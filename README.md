# SKCT 모의고사 도구 (SKCTAddon)

SKCT 온라인 모의고사를 풀 때 화면 오른쪽에 띄워 두는 보조 창입니다.
그림판, 계산기, 시계 앱을 따로 켜 두던 것을 창 하나로 합쳤고, 오른쪽 영역(메모장/그림판, 계산기)은 모의고사 화면 모양에 맞췄습니다.

## 기능

### 타이머
- 켜면 항상 **15분 역산**으로 시작합니다.
- **역산** 버튼을 누르면 스톱워치(0부터 올라감)로 바뀝니다. 바꿀 때마다 시간은 처음 값으로 돌아갑니다.
- 0이 되면 자동으로 멈추고 타이머 줄이 빨간색으로 바뀝니다. 그 상태에서 ▶를 누르면 15:00부터 다시 시작합니다.
- ↺는 돌아가던 중이면 처음부터 이어서 세고, 멈춰 있으면 처음 값에서 기다립니다.
- 📌을 켜면 창이 항상 위에 표시됩니다.

### 메모장 / 그림판
- 탭으로 전환하고, 전환해도 양쪽 내용이 각각 남습니다.
- **메모장 지우기 / 그림판 지우기**는 지금 보이는 쪽만 확인 창 없이 바로 비웁니다.
- 그림판 펜은 검은색 한 가지, 두께도 하나로 고정입니다.

### 계산기
- 모의고사 화면과 같은 배치입니다: `C ⌫ ÷ √` / `7 8 9 ×` / `4 5 6 -` / `1 2 3 +` / `0 00 . =`
- 누른 순서대로 계산합니다(일반 계산기 방식). `2 + 3 × 4 =`는 20입니다.
- 유효숫자 16자리까지 표시하고, 1,234,567처럼 세 자리마다 쉼표를 찍습니다.
- 결과 칸 위에는 마지막 계산식(예: `78 + 2 = 80`)이 나옵니다.

### 숫자패드 고정
- 켜 두면 **다른 창(크롬 등)을 보고 있어도 숫자패드 입력은 이 계산기로** 들어갑니다. 문제를 보면서 계산기를 클릭할 필요가 없습니다.
- 가로채는 키는 숫자패드의 `0~9 + - * / .`와 숫자패드 `Enter`(=)뿐입니다. 일반 숫자열, 메인 Enter 같은 다른 키는 그대로 원래 창으로 갑니다.
- 창을 최소화하면 가로채지 않습니다. `Alt`/`Ctrl`을 누른 채 친 숫자패드 입력(Alt 코드 등)도 그대로 통과합니다.
- NumLock이 켜져 있어야 합니다.
- "계산기" 제목 오른쪽의 **숫자패드 고정** 버튼으로 켜고 끕니다. 어두운 색이면 켜진 상태이고, 기본값은 켜짐입니다.

## 키보드

이 창이 활성일 때, 메모장에 타이핑하는 중이 아니면 아래 키가 계산기로 들어갑니다.

| 키 | 동작 |
|---|---|
| 숫자, `.` | 숫자 입력 |
| `+` `-` `*` `/` | 연산 |
| `Enter`, `=` | 계산 |
| `Backspace` | 한 글자 지우기 |
| `Esc` | C (전체 초기화) |

계산기 버튼을 한 번 누르면 키보드 입력이 메모장에서 계산기로 넘어옵니다.

## 실행과 빌드

윈도우에 기본으로 들어 있는 .NET Framework 4로 만들어서 따로 설치할 것이 없습니다.

1. `build.bat`를 실행하면 같은 폴더에 `SKCTAddon.exe`가 생깁니다.
2. `SKCTAddon.exe`를 실행합니다.

직접 빌드하려면 다음 명령을 씁니다.

```bat
%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:winexe /codepage:65001 /r:System.Windows.Forms.dll /r:System.Drawing.dll /out:SKCTAddon.exe SKCTAddon.cs
```

## 설정 저장

창 위치·크기, 메모장과 계산기 사이 경계, 📌 상태, 마지막 탭, 숫자패드 고정 여부를 `%LOCALAPPDATA%\SKCTAddon\settings.txt`에 저장합니다. 이 파일을 지우면 처음 상태(화면 오른쪽, 세로 가운데)로 돌아갑니다.

## 고치기 쉬운 곳 (`SKCTAddon.cs`)

| 바꿀 것 | 위치 |
|---|---|
| 역산 시간 | `MainForm.CountdownMinutes` |
| 펜 색·두께 | `Canvas.PenColor`, `Canvas.BasePenWidth` |
| 계산기 버튼 배치 | `CalcPanel.Labels`, `CalcPanel.Keys_` |
| 색상 | `Theme` |

## 일부러 넣지 않은 것

뒤로가기, 지우개, 저장, 확인 창은 넣지 않았습니다. 시험 화면과 비슷하게 최대한 단순하게 두려는 목적입니다.

## 참고

- 숫자패드 고정은 윈도우 저수준 키보드 훅(`WH_KEYBOARD_LL`)을 씁니다. 숫자패드 키만 보고, 입력 내용은 어디에도 기록하지 않습니다. 서명 없는 exe가 키보드 훅을 쓰면 일부 백신이 경고할 수 있습니다.
- 계산 방식(누른 순서대로 계산)이 실제 SKCT 계산기와 같은지는 확인하지 못했습니다.
